ARISE · Admin Control Plane — mockup (static, no backend)

Surface: one self-contained HTML page served by FastAPI at /admin (same deploy as the backend, like /privacy). Phone-first at 390px; on ≥900px the bottom tab bar becomes a left rail, user-detail cards flow two-up, and bottom sheets become centered dialogs (max 480px). Nothing here is real data — placeholders only.

  • 01 Login — owner email + password → 12h admin session. Non-owner accounts get the same generic error.
  • 02 Overview — fleet numbers, an Attention list that links straight into actions, and the last audit rows.
  • 03 Hunters — search by email/username, filter chips (Deleted · Unlimited · Inactive 30d), sort by last active.
  • 04 Hunter detail — the workhorse "customer view": identity header + status chips, then grouped cards each with inline actions. Dashed strip = the optional read-only "view as" banner when active.
  • 05 Adjust credits — every mutation: tap → bottom sheet with before/after diff + required reason → confirm. Live stepper.
  • 06 Hard purge — destructive tier: impact counts, grace-window guard, typed username, force toggle, password re-prompt. Try the typed field.
  • 07 Audit — result toast + the new row; filter by actor / action / target; older rows load as skeletons.

ARISE · Admin Control Plane — desktop-first mockup (static, no backend)

Surface: one HTML page served by FastAPI at /admin, desktop-first (1280 frames below) with a deliberate phone quick-action lane (frame 07). Left rail + content; every mutation opens a 420px right drawer that pushes the page (it stays visible) with a before → after diff, a required reason, and Confirm. Placeholders only — nothing here is real data.

  • 01 Hunters — filter chips + search, dense sortable table, owner row with ∞ + ADMIN, deleted row dimmed.
  • 02 Hunter detail — identity header, two-column card grid, Danger zone full-width, Adjust-credits drawer open (live stepper).
  • 03 Purge drawer — deleted hunter; grace guard, per-table impact, FORCE, typed-email unlock (live), reason, re-auth.
  • 04 Audit — filter row, table, one row expanded with before/after JSON side by side, success toast top-right.
  • 05 Overview — six stat tiles, Attention list with deep links, recent audit rows.
  • 06 Catalog + Settings — products table with an edit drawer for scan_50; Settings read-only ("edit on Railway").
  • 07 Phone lane — Hunters results + Hunter detail in phone order with the Grant-unlimited sheet; tabs Hunters · Audit · Overview only.
